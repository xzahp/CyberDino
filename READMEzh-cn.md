# CyberDino 🦖

**CyberDino** 是一个用 Scratch 3.0 做的射击小游戏，配一套自己的在线排行榜网站。用橙子打恐龙、上下躲闪、冲上榜——既能零扩展离线玩，也能用完整账号系统和在线排行榜联网玩。

> 🎯 **选版本一句话**：官方 Scratch 3.29.1 用 **V3.2**；想上排行榜用 **V3.0 + TurboWarp**。

## ✨ 功能特点

- 🦖 **经典街机射击**——上下移动、空格发射橙子打恐龙、每打倒 5 只难度递增、受伤后 1 秒无敌。
- 🖥️ **四个完整界面**——开始页、游戏中、结算页、排行榜页，各有独立背景。
- 📱 **手机触控**——屏幕上的 ▲ / ▼ / 发射 三个按钮；电脑用键盘（空格 / ↑ / ↓）。
- 🌐 **在线排行榜**——自动判断在线/离线；提交成绩、查看榜单、注册登录一应俱全。
- 🛡️ **基础防刷**——分数上限、名字长度限制、同 IP 提交间隔、成绩强制归属账号。
- 🔧 **完全可复现**——每个版本都带 Python 构建 + 验证脚本和真机测试证据。
- 🧩 **零扩展离线版**——V3.2 无需任何扩展、音效或字体声明，官方 Scratch 3 直接能开。
- 🆓 **免费开源**——MIT 许可证，无广告、无追踪。

## 🎮 怎么玩

**官方 Scratch 3（推荐）**：打开 `V3.2/CyberDino-V3.2-官方Scratch兼容版.sb3`，点绿旗。不用注册、不用联网。等 5~10 秒蓝色加载遮罩消失就成功了。（下面那行「载入声音 / 载入角色 / 正在创建积木」只是轮播动画文案，不用管。）

**在线排行榜**：在网站注册登录后点「在线玩」；或用 TurboWarp 打开 `V3.0/CyberDino-V3.0.sb3`。

**操作**：
- 电脑：`空格` 发射、`↑` `↓` 上下躲闪。
- 手机：按住画面上的 ▲ / ▼ / 发射 按钮。
- 改名字：开始页右上角「✎ 改名字」；不换就用默认名。

打倒 20 只通关，每 5 只恐龙更快，3 条命，被撞后 1 秒无敌。

## 🛠️ 怎么运行网站

排行榜网站在 `网站源码/` 目录（原生 PHP + MySQL 后端）。

1. 建一个 MySQL 数据库和 `rankings` 表（见 `文档/网站部署说明.md`）。
2. 复制示例配置并填入你自己的值——**切勿把真实密钥提交到仓库**：

   ```bash
   cp .env.example .env
   # 把 .env 里填成你自己的数据库 / FTP / token 值，
   # 再写进 网站源码/cyberdino_config.php（务必放在 web 根目录之外）。
   ```

3. 把 `网站源码/wwwroot/` 上传到站点根目录（如 `wwwroot` / `htdocs`）。
4. 跑一次性建表脚本，然后**立刻删除 `install.php` / `_clean.php`** 并改掉默认站长密码。
5. 浏览器打开你的域名，验证 `/api/rank.php?action=ping` 返回 `PONG`。

> ⚠️ 排行榜接口同时支持**纯文本**（给 Scratch 解析，如 `1|名字|23;`）和 **JSON**（加 `format=json`）。改接口时请保留纯文本格式。

## 📁 目录结构

```
CyberDino/
├─ README.md                  ← 本文件（英文）
├─ READMEzh-cn.md             ← 中文版
├─ LICENSE                    ← MIT 许可证
├─ .env.example               ← 配置模板（无真实密钥）
├─ V1.0/ ... V3.2/            ← 5 个独立游戏版本 + 源码与验证证据
│   └─ 源码与验证证据/          ← build.py / verify.py / 截图 / 测试数据
├─ 网站源码/                   ← 排行榜网站源码（PHP）
│   ├─ wwwroot/               ← 要上传的站点根目录
│   ├─ cyberdino_config.php   ← 数据库配置（放 web 根之外）
│   ├─ deploy.py              ← FTP 上传脚本
│   └─ install.php            ← 一次性建表脚本（用完删）
└─ 文档/                       ← 部署说明、故障修复、站长手册
```

每个版本文件夹都自包含——某版出问题，旧版照样能玩。
